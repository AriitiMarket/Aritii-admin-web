┌─ DATA FLOW ───────────────────────────────────────────────────────────────────┐
│                                                                               │
│  1. SELECTION                                                               │
│     Admin clicks HierarchySelector dropdown                                 │
│     └── HierarchySelector calls setSector(node)                            │
│         └── HierarchyContext updates state                                  │
│             └── Persists to localStorage                                    │
│                 └── Notifies all subscribers (pages)                        │
│                                                                               │
│  2. PAGE RENDER                                                             │
│     HomePage calls useHierarchy()                                           │
│     └── Gets { selection, ... } from HierarchyContext                      │
│         └── useAsync(() =>                                                  │
│             platformAdminService.getStatsByHierarchy({                      │
│               sectorId: selection.sector?.id                                │
│             })                                                               │
│         )                                                                    │
│         └── API call includes hierarchy params                              │
│                                                                               │
│  3. BACKEND FILTERING                                                       │
│     platformAdminService.getStatsByHierarchy({sectorId})                   │
│     └── http.get('/admin/platform/stats', {                                │
│           params: { sectorId: '...' }                                       │
│         })                                                                   │
│     └── Backend filters query:                                              │
│         SELECT * FROM stats WHERE sector_id = $1                            │
│                                                                               │
│  4. PAGE UPDATE                                                             │
│     useAsync detects selection change                                       │
│     └── Re-fetches data from API                                            │
│         └── Page re-renders with new data                                   │
│             └── All tables, charts, KPIs update instantly                   │
│                                                                               │
│  5. PERSISTENCE                                                             │
│     User navigates to OrdersPage                                            │
│     └── DashboardLayout renders HierarchySelector                          │
│         └── useHierarchy() returns cached selection from context            │
│             └── OrdersPage sees same hierarchy (not lost!)                  │
│                 └── OrdersPage filters orders by same sector/business       │
│                                                                               │
└───────────────────────────────────────────────────────────────────────────────┘

┌─ HIERARCHY LEVELS ────────────────────────────────────────────────────────────┐
│                                                                               │
│  HierarchyContext.selection = {                                             │
│    platform: HierarchyNode,           ← Always present, represents "All"    │
│    region: HierarchyNode | null,      ← E.g., "East Africa"                │
│    city: HierarchyNode | null,        ← E.g., "Nairobi"                    │
│    area: HierarchyNode | null,        ← E.g., "Central Business District"  │
│    sector: HierarchyNode | null,      ← E.g., "Quick Commerce"             │
│    business: HierarchyNode | null,    ← E.g., "FreshMart Ltd"              │
│    shop: HierarchyNode | null,        ← E.g., "FreshMart - Westlands"      │
│  }                                                                            │
│                                                                               │
│  Cascading Clearing:                                                         │
│  └── Select region                                                           │
│      └── Auto-clear: city, area, sector, business, shop                     │
│  └── Select city                                                             │
│      └── Auto-clear: area, sector, business, shop                           │
│  └── Select sector                                                           │
│      └── Auto-clear: business, shop                                          │
│                                                                               │
└───────────────────────────────────────────────────────────────────────────────┘
